# /model 选项卡验证记录（2026-10-10）

## 行为

不带参数的 `/model` 读取 Codex 原生 `model/list` 目录，展示名称、说明、当前模型标记、分页按钮及恢复 MAC 默认按钮。切换仍沿用既有 `/model 模型名` 行为：仅空闲项目可切换，下一条消息开始新对话，项目文件及 Owner 模型不变。

目录连接不创建 thread/turn，与项目执行使用相同 Codex 登录和全局配置；查询有超时并在 finally 关闭连接。失败或空列表明确提示，不提供猜测模型。卡片绑定项目、提交者和当前模型，失效卡片拒绝执行；回调选择写入既有事件审计字段。

仅支持既有 Codex 模型切换能力，不静默切换其他 provider。模型切换的运行中检查移到锁前，并保留锁内复查，避免已知正在执行的项目等待整轮执行锁。

慢目录查询完成或失败后、发送新卡片之前再次冻结进度卡；模型卡回调同样遵循时间线轮换。切换调用携带 `expected_project_id`，防止轮换等待期间用户改变当前项目后误切其他项目。
